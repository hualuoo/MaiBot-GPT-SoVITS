# 使用

## 命令与语音工具

```text
/tts_status
/tts 你好，这是一条语音合成测试。
```

然后可以对机器人说“用语音说一句你好”，测试大模型调用工具。如果模型没有调用工具，先用 `/tts` 命令确认合成链路正常。

调用链：命令 / 工具 / 自动语音 → `POST /tts`（非流式 WAV）→ Base64 → MaiBot `send.custom("voice")` → 平台适配器。

## 自动语音回复

在 MaiBot 完成分句、即将发送每条文字时触发（`send_service.before_send`）：

- **按概率**：0% 不转换，100% 每条合格文字都尝试转换。
- **每 N 条**：按聊天流计数，每 N 条合格文字转换一条。
- **最短间隔**：间隔内、正在合成或执行设置任务、文字超过字数上限时，直接发送文字，不排队。
- **按情感选择模型**（仅角色模式，“跟随回复情感”）：优先使用消息中的情感标记；没有标记且启用了多个情感时由 MaiBot 的 LLM 判断（见 [情感分类](emotion-classification.md)），LLM 不可用或关闭时用中英文关键词保守匹配；遇到否定、冲突或未启用的情感时使用默认情感。
- **保留文字**：关闭时语音替换文字；开启时同一条消息同时包含文字和语音。

命令、代码块、已有语音或图片等非纯文字消息，以及插件自己的错误提示都不会被转换。合成失败或超时时照常发送原文字。QQ 语音不能附带引用，转换成功后会自动去掉引用。

建议先在第四步试听确认声音正常（可选），再把概率设为 100%、间隔 5 秒进行验证，确认正常后再调低概率。

## 合成日志

每次调用语音合成（`/tts` 命令、语音工具、自动语音、设置页试听和加载模型），插件都会在 MaiBot 日志里输出两行，终端和 WebUI「日志」页都能看到。WebUI 日志页的模块一栏显示为 `plugin.local.gpt-sovits-tts`，也可以搜索 **“语音合成”** 筛选：

```text
[语音合成] 开始 · 命令 /tts · 群 测试群（123456） · 角色 黍（启用 5 个情感） · 文本 10 字「唉，今天的雨下个不停」
[语音合成] 完成 · 命令 /tts · 群 测试群（123456） · 角色 黍 · 情感 难过（LLM 判断，fast_model/gpt-6.1-sol，2.4 秒） · 切换模型 GPT shu_sad.ckpt、LoRA shu.pth（1.8 秒） · 合成 3.1 秒 · 音频 5.2 秒 / 168 KB · 已发送 · 共 7.5 秒 · 文本「唉，今天的雨下个不停」
```

| 结果 | 级别 | 含义 |
|---|---|---|
| 开始 / 完成 | INFO | 已开始合成 / 合成并发送（或转换）成功 |
| 未执行 | INFO | 合成前就被拒绝，例如冷却中、正在合成其他语音、文本超长、聊天流不在白名单 |
| 失败 | WARNING | 合成过程中出错，附带原因；自动语音会保留原文字 |
| 已取消 | INFO | 插件卸载或任务被取消 |

- **来源**：命令 /tts、语音工具、自动语音、设置页试听、设置页加载模型。
- **聊天**：命令和自动语音取自消息里的群名/群号或私聊对象；语音工具拿不到消息时，沿用该聊天最近一次命令记录的名称，否则显示聊天流 ID 前 8 位。
- **情感**（角色模式）：LLM 判断（模型任务/模型、耗时或“缓存结果”）、指定、消息情感标记、关键词规则或默认情感；LLM 失败时写明改用了哪种结果及原因。
- **模型**：切换了哪些权重文件及耗时，或“沿用已加载的模型”/“使用服务端当前加载的模型”。
- 文本只显示前 40 个字。

### 日志颜色（天蓝色）

MaiBot 按日志的模块名决定颜色，配置写在 MaiBot 自己的 `src/common/logger_color_and_mapping.py` 里，插件运行在独立进程中，无法自行设置。要让本插件的日志在终端和 WebUI 日志页显示为天蓝色（`#87d7ff`，即 MaiBot 终端里 INFO 时间戳使用的“天蓝色”），在 `MODULE_COLORS` 中加入一行：

```python
    "plugin.local.gpt-sovits-tts": ("#87d7ff", None, False),  # GPT-SoVITS 语音合成插件：天蓝色
```

另外，MaiBot 的 WebUI 日志页在打开或刷新时加载的历史日志，会把插件日志的模块显示为“插件运行器”，因此不会套用颜色（实时推送的日志不受影响）。如需历史日志也显示颜色，把 `src/webui/logs_ws.py` 中 `_format_log_entry` 的第一行改为与实时推送一致：

```python
    module_name = str(raw_entry.get("logger_name") or raw_entry.get("logger") or raw_entry.get("module") or "")
```

修改后需要**重启 MaiBot** 才会生效（重载插件不够）；WebUI 前端不需要重新构建。

- 终端：`bot_config.toml` 中 `[log] color_text = "full"` 时模块名和内容都是天蓝色，`"title"` 时只有模块名着色，`"none"` 不着色；时间戳仍按日志级别着色（WARNING 为黄色）。
- WebUI：模块名和内容显示为天蓝色，级别一栏仍按级别着色（WARN 为黄色），失败行仍能区分。
- 这两处属于 MaiBot 本体的文件，更新 MaiBot 时可能产生冲突：更新前可用 `git checkout -- src/common/logger_color_and_mapping.py src/webui/logs_ws.py` 还原，更新后再按上面的说明重新添加；源码仓库中的 `maibot-patch/sky-blue-log.patch` 可在 MaiBot 根目录用 `git apply` 一次加回（发行包不含此文件）。
