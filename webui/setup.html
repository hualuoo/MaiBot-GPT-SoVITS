还没有部署 GPT-SoVITS？查看部署教程

本插件通过 GPT-SoVITS 自带的 api_v2.py 接口合成语音，需要先在本机或局域网内的电脑上部署并启动它。本页无法直接打开外部链接：点击链接文字即可全选，按 Ctrl+C 复制后粘贴到浏览器打开。

1. 获取 GPT-SoVITS

  • Windows 整合包（推荐）：自带运行环境和全部底模，解压即用。下载最新的 GPT-SoVITS-v5-20261005.7z；RTX 50 系列显卡下载 GPT-SoVITS-v5-20261005nvidia50x0.7z。解压到不含中文和空格的目录，例如 D:\GPT-SoVITS。
    Hugging Face 下载：https://huggingface.co/lj1995/GPT-SoVITS-windows-package/resolve/main/GPT-SoVITS-v5-20261005.7z
    RTX 50 系列：https://huggingface.co/lj1995/GPT-SoVITS-windows-package/resolve/main/GPT-SoVITS-v5-20261005nvidia50x0.7z
    全部版本：https://huggingface.co/lj1995/GPT-SoVITS-windows-package/tree/main
  • 源码安装（Windows / Linux / macOS，需要先安装 Conda）： 
    git clone https://github.com/RVC-Boss/GPT-SoVITS
cd GPT-SoVITS
conda create -n GPTSoVits python=3.10
conda activate GPTSoVits
pwsh -F install.ps1 --Device CU128 --Source HF
    Linux / macOS 把最后一行换成 bash install.sh --device CU128 --source HF。没有 NVIDIA 显卡时 Device 填 CPU（macOS 可填 MPS）；较旧的显卡也可填 CU126。安装脚本会从 Hugging Face 自动下载 v1～v4、v2Pro 底模；v5 底模需按第二步说明另行下载。

2. 启动 API 服务

插件需要的是 API 服务，不是 go-webui.bat 打开的网页界面。在 GPT-SoVITS 根目录打开终端运行：

python api_v2.py -a 127.0.0.1 -p 9880 -c GPT_SoVITS/configs/tts_infer.yaml

整合包用户可在根目录新建 go-api.bat，写入以下内容后双击运行：

@echo off
cd /d "%~dp0"
set "PATH=%~dp0runtime;%PATH%"
runtime\python.exe api_v2.py -a 127.0.0.1 -p 9880 -c GPT_SoVITS/configs/tts_infer.yaml
pause

浏览器打开 http://127.0.0.1:9880/docs，能看到接口文档就说明启动成功。使用期间保持这个窗口运行。

3. 回到本页测试连接

在上方“接口地址”填写 http://127.0.0.1:9880，点击“保存并测试连接”，成功后进入第二步选择底模。

常见问题

  • 9880 是 API 端口；9872、9874 是网页界面（Gradio），填在这里会连接失败或返回网页。
  • 只有 CPU：把 GPT_SoVITS/configs/tts_infer.yaml 中 custom 段改为 device: cpu、is_half: false 再启动；CPU 合成较慢，建议选 v2 或 v2Pro 底模，并在第一步把请求超时调大。
  • GPT-SoVITS 装在另一台电脑：启动参数改为 -a 0.0.0.0，这里填写那台电脑的局域网 IP，并在防火墙放行 9880 端口，不要暴露到公网。第二步的模型目录和第三、四步的参考音频必须是那台电脑上的路径。
  • GPT-SoVITS 运行在 Docker 中时，容器里的 127.0.0.1 指容器本身，请填写 MaiBot 所在机器能访问的地址。
  • 连接测试只检查接口是否可达，不加载模型；首次合成需要加载模型，会比较慢。

完整教程见 GitHub：https://github.com/RVC-Boss/GPT-SoVITS

怎么选

  • 有 NVIDIA 显卡、想要最像参考音频：v5turbo。v5 不训练也能获得更高的音色相似度，输出 48 kHz。
  • 只有 CPU 或想要更快：v2 或 v2Pro。推理快、占用低，输出 32 kHz。
  • 自己训练、训练素材音质一般：v2Pro / v2ProPlus，对音质一般的训练集比 v3/v4 更稳。
  • 已经有某个版本训练好的模型：选与它相同版本的底模。
版本特点需要的文件（都在 GPT_SoVITS/pretrained_models/ 下，保留子目录）
v5turbo最新（2026-10）。默认 4 步采样，速度较快；48 kHz；参考文本必填s1v3.ckpt、gsv-v5-pretrained/s2Gv5turbo.pth、gsv-v5-pretrained/vocoder.pth
v5dev与 v5turbo 同代，默认 32 步采样并启用 CFG，明显更慢；参考文本必填s1v3.ckpt、gsv-v5-pretrained/s2Gv5dev.pth、gsv-v5-pretrained/vocoder.pth

参考音频和角色文件放在哪里？

合成时由 GPT-SoVITS 服务直接读取参考音频和模型文件，所以请把它们放在 GPT-SoVITS 安装目录（第二步填写的本机模型目录）下的指定文件夹里。本页不提供上传，文件夹不存在时请自己新建。插件和 GPT-SoVITS 需要在同一台电脑上，或能用同一路径访问这些文件。

普通模式：参考音频

  1. 把参考音频复制到：<GPT-SoVITS 安装目录>/maibot_refs（可以再建子文件夹分类）。
  2. 要求：3～10 秒、单人说话、清晰、没有背景音乐和杂音；支持 wav、mp3、flac、ogg、m4a。
  3. 点击“刷新参考音频”，在下拉框中选择；填写参考音频对应的文字（v3、v4、v5 底模必填，要与音频内容一字不差）、参考音频语言和合成文字语言，再点击“仅保存设置”。

角色模式：角色文件夹

  1. 把整个角色文件夹复制到：<GPT-SoVITS 安装目录>/maibot_roles，每个角色文件夹里放一个 role.json，结构为 maibot_roles/角色名/role.json。
  2. role.json 里每个情感写明 gpt、sovits、ref_audio（文件名相对角色文件夹）和 ref_text；这些文件放在同一个角色文件夹里。如果写了 base_model（例如 v2Pro / v2ProPlus 需要的 pretrained_eres2netv2w24s4ep4.ckpt），该文件必须已安装在 GPT-SoVITS 的 GPT_SoVITS/pretrained_models 中（这里是 sv 文件夹），角色文件夹里的副本不会被使用。
  3. 点击“刷新角色列表”，选择角色和要启用的情感，再点击“读取角色配置”。

不要放到插件的 data 目录：插件不会在那里查找，而且在 MaiBot 中卸载插件时插件目录（包括 data）会被删除。

第五步 · 自动语音回复

自动语音回复

默认关闭，不改变现有回复行为。只处理普通纯文字消息；voice / image（语音 / 图片）、混合消息与插件提示会跳过。语音成功后自动取消指定消息引用，避免平台拒发；转换失败保留原文字和引用。

启用后才按以下规则转换后续文字；本页保存不发 QQ、不合成，也不加载模型。

概率 0% 永不转换，100% 每条参与转换；每 N 条按 MaiBot 语义分句后的实际消息计数；插件不覆盖 MaiBot 分段，当前使用原生 LLM 语义断句。两种方式都会受最短间隔限制，间隔内会跳过而非排队。

整数 0～100，默认 50；仅按概率时使用。

整数 1～1000，默认 3；按聊天流统计实际语义消息，语音、图片和插件提示不计入。

0～3600 秒，默认 5；间隔未满会跳过，0 为不额外限制。

仅角色模式有效。

优先使用消息已有的情感标记；没有标记时，若第三步启用了 2 个以上情感并开启 LLM 判断，则调用 MaiBot 的 LLM 判断（每句一次额外调用），LLM 失败时再保守地按关键词推断；不明确时使用默认情感，只选择第三步已勾选情感。关闭后始终使用默认情感；普通模式只使用当前单一 LoRA（或底模），不选择情感，不混合 LoRA。
